Historien-Import

Garmin Backup-FIT (z.B. PrimaryTrainingBackup.fit) importieren. Extrahiert Datum, Dauer und Ø-HF. Duplikate (gleicher Tag) werden erkannt und übersprungen.

Garmin-Sync

Aktivitäten aus dem automatischen Garmin-Sync (garmin/data.json) in die App übernehmen. Bereits vorhandene Tage werden übersprungen; Tage mit mehreren Aktivitäten werden zu einer Einheit zusammengefasst.

Trainingsprofil & Prinzipien

Beschreibe hier deine Trainingsmethodik, Ziele, HF-Werte und Vorgaben. Die KI nutzt diese Informationen automatisch bei jeder Analyse.

GitHub PAT (Garmin-Sync)

Ein Fine-grained Personal Access Token, mit dem der „Garmin"-Button oben im Log den Sync auslöst. Empfohlener Scope: nur dieses Repo, Berechtigung Actions: Read and write. Wird verschlüsselt in Supabase gespeichert und ist nur für dich zugänglich (RLS). Ohne Token bleibt der Garmin-Button deaktiviert.

Anthropic API Key

Der Key wird nur lokal in deinem Browser gespeichert – nie auf GitHub oder einem Server. Du findest ihn unter console.anthropic.com → API Keys.
